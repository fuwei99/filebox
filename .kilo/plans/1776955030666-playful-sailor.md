# Server Password Auth Plan

## 概述

在 config.json 中新增 `serverAuth.enabled` 和 `serverAuth.password` 字段。开启后，上传 API 需要验证服务器密码签发的 JWT token，前端页面顶部增加登录按钮，输入服务器密码后获取 JWT 并存储到 localStorage，30 天有效。下载不受影响。

---

## 后端变更

### 1. `backend/src/config.ts`

`AppConfig` 新增：

```ts
serverAuth: {
  enabled: boolean;
  password: string;
};
```

`defaultConfig` 新增：

```ts
serverAuth: {
  enabled: false,
  password: '',
},
```

`mergeConfig` 处理嵌套合并。

### 2. `backend/src/routes/auth.ts` — 新增服务器密码登录接口

新增路由 `POST /api/auth/server-login`：
- 请求体：`{ password: string }`
- 校验 `appConfig.serverAuth.password === password`
- 成功：用 `jwt.sign({ type: 'server' }, appConfig.jwtSecret, { expiresIn: '30d' })` 签发 token
- 失败：401

新增路由 `GET /api/auth/server-status`：
- 返回 `{ enabled: boolean }` — 前端据此判断是否显示登录按钮
- 无需认证

### 3. `backend/src/middleware/auth.ts` — 新增 `requireServerAuth` 中间件

```ts
export const requireServerAuth = (req, res, next) => {
  if (!appConfig.serverAuth.enabled) return next(); // 未开启则放行
  // 开启时，检查 Bearer token，jwt.verify 后判断 type === 'server'
  // 无效则 401
};
```

### 4. `backend/src/routes/upload.ts` — 应用中间件

在 upload 路由前挂载 `requireServerAuth`，仅保护上传接口：
- `POST /` (单文件)
- `POST /batch` (批量)

下载接口不做变更。

---

## 前端变更

### 5. `frontend/src/api/index.ts` — 添加请求拦截器

为现有的 `api` axios 实例添加请求拦截器：
- 从 `localStorage.getItem('filebox_server_token')` 读取 token
- 如果存在，附加 `Authorization: Bearer <token>`

添加 401 响应拦截器：
- 收到 401 时，清除 `filebox_server_token`，触发自定义事件 `server-auth-expired`

### 6. 新增 `frontend/src/api/serverAuth.ts`

```ts
export const serverLogin(password: string) → POST /api/auth/server-login
export const getServerAuthStatus() → GET /api/auth/server-status
```

### 7. 新增 `frontend/src/contexts/ServerAuthContext.tsx`

轻量 context，仅处理服务器密码认证（与 chat 的 AuthContext 完全独立）：

- state: `isServerAuthed`, `isAuthEnabled`, `isLoading`
- 初始化时：
  1. 调用 `getServerAuthStatus()` 判断是否开启
  2. 如果开启，检查 `localStorage.getItem('filebox_server_token')`
  3. 如果有 token，尝试调 `/api/auth/server-status` 验证（或直接信任 localStorage 中的 token，401 时清除）
- `login(password)`: 调用 `serverLogin`，成功存 token
- `logout()`: 清除 token
- 监听 `server-auth-expired` 事件自动登出

### 8. `frontend/src/App.tsx` — 集成

- 包裹 `<ServerAuthProvider>`
- Header 区域新增登录按钮：
  - 未开启 serverAuth：不显示按钮
  - 开启但未登录：显示「登录」按钮，点击弹出密码输入模态框
  - 已登录：显示「已登录」状态 + 退出按钮
- 密码输入模态框：单字段（密码），提交按钮，错误提示
- 上传时如果 401，自动弹出登录框

### 9. `frontend/src/main.tsx` — 包裹 Provider

App 组件需要被 `ServerAuthProvider` 包裹，在 `main.tsx` 中处理。

  }
